S1 — Foundation and Reset

This design system supports a street photography portfolio with an earthy, editorial aesthetic.

Reset Strategy

A selective CSS reset maintains useful browser defaults while creating consistency across page elements.

  • Global border-box sizing makes element dimensions more predictable.
  • Default body margins are removed to allow intentional page spacing.
  • Images are constrained to their containers to prevent horizontal overflow.
  • Form controls inherit typography for visual consistency.

Semantic Color Tokens

Semantic tokens describe how colors are used rather than specifying individual color values. They allow themes to change without rewriting component styles.

Token Default Value Intended Role

--color-surface #FFFFFF Cards and raised surfaces
--color-text #252B27 Body text
--color-heading #203D32 Headings and titles
--color-border #A8B9A0 Borders and dividers
--color-action #203D32 Primary buttons and actions

Typography Documentation

Display font: Cormorant Garamond, used for headings and editorial titles. Fallback: Georgia, serif.

Body font: Inter, used for paragraphs, navigation, labels, and controls. Fallback: Arial, sans-serif.

Font source: Google Fonts. Both font families use the SIL Open Font License 1.1.

Available weights and styles: Cormorant Garamond uses regular, medium, semibold, and bold weights, plus regular italic. Inter uses regular, medium, semibold, and bold.

Responsive sizing: Large headings use clamp() to scale between minimum and maximum sizes according to the viewport.

Reading measure: Longer text is limited to 80ch to maintain readable line lengths.

Fallback strategy: If Google Fonts cannot load, the browser displays Georgia or Arial followed by generic serif or sans-serif fonts.
